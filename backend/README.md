# clinic_monday_27278

AUCA Web Technology clinic project (Quiz 1 and Quiz 2).

## Run
1. Create a PostgreSQL database named `clinicdb`.
2. Set `SPRING_DATASOURCE_PASSWORD` to the password for the PostgreSQL user (`postgres` by default).
3. From the backend folder, run `.\mvnw.cmd spring-boot:run` on Windows or `./mvnw spring-boot:run` on macOS/Linux.
4. App URL: http://localhost:8082

## Postman
- Quiz 1: `clinic-quiz.postman_collection.json`
- Quiz 2: `clinic-quiz2.postman_collection.json`

Import the file in Postman, then send the requests.
